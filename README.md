# Studio pack (engine v4 studio mode)

Curated CC0 recordings used by `djvelvetgrey/v2/studio.py` (brief `"instruments": "studio"`).

Sources, both **CC0 1.0** (public domain, no attribution required):
- VSCO 2 Community Edition — https://github.com/sgossner/VSCO-2-CE
- Versilian Community Sample Library (VCSL) — https://github.com/sgossner/VCSL

Built with `djvelvetgrey/tools/build_studio_pack.py` and level-matched with `djvelvetgrey/tools/calibrate_studio_pack.py`.
`index.json` maps every file back to its source sample.

Use: `git clone --depth 1 -b samples https://github.com/ramatladi/videosyndication /home/claude/studio_pack`
